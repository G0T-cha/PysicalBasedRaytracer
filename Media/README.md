# 参与介质 (Media)

`Media` 模块负责模拟光线在“参与介质”（Participating Media）中的传播行为。与真空不同，介质（如雾、烟、云、次表面散射材质）充满了微小的粒子，光线在穿过它们时会发生**吸收 (Absorption)** 和**散射 (Scattering)**。

本模块为 `VolPathIntegrator` 提供了必要的物理模型和采样接口。

## 1. 核心接口与基础概念 (`Medium.h`)

### 1.1. 相位函数 (`PhaseFunction`)
描述了光线在介质中与粒子发生碰撞后，散射到各个方向的概率分布。它是介质体的“BRDF”。
- **`HenyeyGreenstein`**:
  - 最常用的参数化相位函数。
  - 通过一个不对称参数 g (取值范围 [-1, 1]) 控制散射特性：
    - g 大于 0: 前向散射（Forward scattering，如云、水）。
    - g 小于 0: 后向散射（Backward scattering，如石头）。
    - g 等于 0: 各向同性散射（Isotropic scattering，向所有方向均匀散射）。

### 1.2. 介质交互 (`MediumInteraction`)
类似于表面的 `SurfaceInteraction`，它记录了光线在介质内部某一点发生散射时的详细信息（位置、入射方向、所在的介质实例、相位函数等），供积分器计算散射光照。

### 1.3. `Medium` (抽象基类)
定义了所有介质必须实现的两个核心物理操作：
- **`Tr(ray, sampler)` (透射率)**:
  - 计算光线沿射线 `ray` 传播特定距离后，**没有**发生任何吸收或散射的比例（即根据比尔定律衰减后的剩余能量比例）。
- **`Sample(ray, sampler, ...)` (传播采样)**:
  - 重要性采样光线在介质中的自由程（Free path）。
  - 决定光线是在介质内部撞到了粒子（返回 `MediumInteraction`），还是成功穿过了介质（返回边界表面的 `SurfaceInteraction`）。

## 2. 具体介质实现

### 2.1. `HomogeneousMedium` (均匀介质)
最简单的介质类型，其光学属性（吸收系数 sigma_a、散射系数 sigma_s）在空间中处处相等。
- **典型应用**: 均匀的雾、浑浊的水、有色玻璃。
- **实现原理**:
  - **透射率 `Tr`**: 存在解析解。直接使用**比尔-朗伯定律 (Beer-Lambert Law)** 计算：透射率随距离呈指数衰减。衰减系数为吸收系数与散射系数之和。计算非常高效。
  - **采样 `Sample`**: 自由程符合指数分布，可以直接通过逆变换算法进行完美的重要性采样。

### 2.2. `GridDensityMedium` (网格密度介质/非均匀介质)
用于模拟密度在空间中变化的复杂介质。
- **典型应用**: 烟雾、云层、爆炸火焰。
- **数据结构**: 使用 3D 浮点数数组（体素网格）存储空间中的密度分布。实际的散射/吸收系数等于基础系数乘以当前点的密度值。
- **实现原理 (基于零散/虚粒子技术)**:
  由于密度不均匀，比尔定律不再适用，必须使用蒙特卡洛方法进行无偏估计。
  - **采样 `Sample`**: 使用 **Delta Tracking (Woodcock Tracking)**。在介质中引入一种虚拟的“假”粒子，使得总密度在空间中处处相等（均匀化），然后通过随机拒绝一部分与“假”粒子的碰撞来恢复真实的非均匀分布。
  - **透射率 `Tr`**: 使用 **Ratio Tracking**。这是 Delta Tracking 的一个变种，专门用于估计透射率，相比传统的射线步进 (Ray Marching) 具有更低的方差和无偏性。
