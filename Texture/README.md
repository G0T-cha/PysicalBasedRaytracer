# 纹理系统 (Texture)

纹理模块负责将 3D 表面的几何信息映射为特定的材质属性值（如颜色、粗糙度等）。本项目实现了一个功能完备的纹理系统，不仅支持基础的常量和图像映射，还内置了基于**微分**的高质量抗锯齿滤波技术。

## 1. 核心接口

### 1.1. `Texture<T>` (抽象基类)

`Texture.h` 定义了所有纹理的统一接口。它是一个模板类，`T` 可以是 `Spectrum`（用于反照率等颜色信息）或 `float`（用于粗糙度、金属度等单通道信息）。

- **`virtual T Evaluate(const SurfaceInteraction& isect) const = 0;`**
  - 这是纹理求值的唯一入口。
  - 材质系统在着色时调用此函数，传入包含完整几何信息（位置、UV、以及**关键的光线微分**）的 `SurfaceInteraction` 对象，获取该点对应的纹理值。

### 1.2. `TextureMapping2D` (2D 映射接口)

定义了如何将 3D 表面的交互点映射到 2D 纹理空间 (s, t)。

- **核心职责**:
  - 计算纹理坐标 (s, t)。
  - **计算纹理微分**: 必须计算并返回纹理坐标对屏幕坐标 x 和 y 的偏导数（即代码中的 `dstdx` 和 `dstdy`）。这两个向量定义了屏幕像素在纹理空间中覆盖的“足迹”(Footprint) 的形状和大小，是后续高质量纹理滤波的基础。
- **`UVMapping2D` 实现**:
  - 最常用的标准映射。直接使用几何体提供的 UV 坐标。
  - 支持通过缩放 (`su, sv`) 和偏移 (`du, dv`) 来调整纹理在模型上的分布。

## 2. 纹理实现

### 2.1. `ConstantTexture<T>` (常量纹理)

最简单的纹理实现，内部仅持有一个固定的 `T value`。无论传入什么几何信息，`Evaluate` 始终返回该常量值。常用于定义均一的材质属性。

### 2.2. `ImageTexture<T>` (图像纹理)

将磁盘上的图像文件（支持 .png, .jpg, .hdr 等多种格式，通过 `stb_image` 加载）用作纹理源。

- **数据流**:
  1. `Evaluate` 被调用时，首先利用持有的 `TextureMapping2D` 计算出纹理坐标 (s,t) 及其微分 `dstdx`, `dstdy`。
  2. 将这些坐标和微分信息传递给底层的 `MIPMap` 进行具体的纹素查找和滤波。
- **全局缓存**:
  - 为了优化内存和性能，实现了基于 `TexInfo`（包含文件名、色彩空间、滤波模式等参数）的全局静态缓存。相同参数的纹理文件只会被加载和处理一次。

## 3. 高质量滤波 (MIPMap)

`MIPMap` (`MIPMap.h/.cpp`) 是本模块的核心算法支撑，它通过预计算图像金字塔来解决纹理走样问题（远处产生噪点或摩尔纹）。

- ### 3.1. 构建与预处理
  - **重采样 (Resampling)**:
    - 为了高效的层级查询，MIPMap 要求纹理分辨率必须是 2 的幂次方（Power of Two）。
    - 如果输入图像不满足此条件，构造函数会自动使用高质量的 **Lanczos 滤波器**将其重采样至最近的 2 的幂次方分辨率，以最大限度保留图像细节。
  - **金字塔构建 (Pyramid Construction)**:
    - 这是一个预计算过程，生成一系列分辨率逐级减半的图像层级（Levels）。
    - **第 0 层**: 存储原始（或重采样后的）最高分辨率图像。为了提高纹理采样时的 CPU 缓存命中率，使用了**分块存储 (Blocked Array)** 的内存布局。
    - **后续层级**: 采用迭代方式构建。第 i 层图像由第 i - 1 层图像进行 **2x2 均值滤波 (Box Filter)** 降采样得到。即，高层级中的每一个纹素的值，等于其在下一层级中对应的 2x2 纹素区域的平均值。
    - **终止条件**: 此降采样过程一直持续，直到纹理的最长边分辨率降至 1（最终得到一个 1x1 的单一颜色层级）。
  - **纹理寻址 (Wrapping Modes)**: 在访问特定层级的纹素（Texel）时，支持三种寻址模式以处理超出 [0,1] 范围的纹理坐标：
    - `Repeat`: 重复纹理（适用于平铺地面等）。
    - `Clamp`: 钳制在边缘像素（适用于非重复物体表面）。
    - `Black`: 超出部分返回黑色。

- ### 3.2. 输入输出工作流

  `MIPMap::Lookup` 的工作依赖于完整的渲染管线数据流：

  1. **输入 (光线微分)**: 从相机生成的光线微分信息，经过与场景的交互（`SurfaceInteraction`），最终被 `TextureMapping2D` 转换为**纹理空间微分** `dstdx` 和 `dstdy`。这两个向量精确描述了一个屏幕像素在当前纹理上覆盖了多大、多扁的区域（即“足迹” Footprint）。
  2. **处理 (层级选择)**: `MIPMap` 利用这些微分向量的模长来计算足迹的宽度。足迹越大，说明纹理被压缩得越厉害（例如远处的地面），算法就会选择更高的金字塔层级进行采样，从而引入恰当的模糊来消除走样。
  3. **输出 (滤波颜色)**: 根据选择的层级（可能是一个浮点数），使用下述的滤波技术计算出最终的平滑颜色值返回给材质系统。

### 3.3. 滤波技术

`MIPMap` 根据传入的微分信息自动选择最佳的滤波策略：

- **三线性插值 (Trilinear Filtering)**:
  - 当纹理映射是各向同性（Isotropy）或性能要求较高时使用。
  - 根据微分向量的模长最大值计算出一个各向同性的过滤宽度，并据此确定一个浮点数层级，最终结果是相邻两个离散层级的**双线性插值**结果的线性混合。
- **EWA 滤波 (Elliptically Weighted Average)**:
  - **高级各向异性滤波**，用于解决以倾斜角度观察纹理时产生的模糊问题。
  - **原理**: 像素在纹理空间中的“足迹”被建模为一个椭圆，其长短轴由微分向量 `dstdx` 和 `dstdy` 决定。
  - **流程**: 选择最合适的 MIPMap 层级（由椭圆短轴决定），扫描椭圆包围盒内的所有纹素，并对位于椭圆内部的纹素进行**高斯加权**平均，从而得到极其精确且无走样的纹理颜色。
